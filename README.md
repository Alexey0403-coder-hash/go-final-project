Проект TODO предназнчен для хранения, добавления, удаления и изменения задач с такими полями, как: дата, название, комментарий. Есть возможность сделать задачу повторяемой через определенный промежуток времени.

В директории `api` находятся обработчики запросов и регистратор этих обработчиков.

В директории `db` находятся функции, которые реализуют запросы БД.

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Список выполненных задач со звездочкой:
1. Реализация возможности определять порт при запуске сервера извне.
2. Реализация возможности определять путь к файлу БД через переменную окружения.
3. Реализация механизма аутентификации.
4. Деплой сервиса посредством Docker.

Для использования переменных окружения используется файл .env со следующими переменными:
TODO_PASSWORD - пароль для аутентификации, если эта переменная будет пустая, то аутентификация будет отключена. Используется `04032001`
TODO_PORT - порт, который будет использовать сервер. Если эта переменная будет пустая, то используется "7540". Используется `7540`
TODO_DBFILE - путь файла БД. Если эта переменная будет пустая, то используется "scheduler.db" Используется `scheduler.db`

В программе присутствует инструкция по сборке Dokerfile и конфигурация запуска compose.yaml.
1. Откройте терминал в корневой директории проекта и выполните `docker compose up -d --build` 
Команда автоматически соберет Docker-образ и запустит контейнер в фоновом режиме.
2. После успешного запуска приложение доступно в браузере по адресу:
`http://localhost:7540`
3. Приложение использует SQLite. База данных хранится в постоянном Docker volume.
